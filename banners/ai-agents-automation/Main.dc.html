This short course is designed to give participants a practical, hands-on introduction to AI agents and workflow automation. Participants learn how to design, build, and deploy intelligent agents that connect tools, handle repetitive tasks, and support real-world decision-making. The programme combines core concepts with guided projects, so learners finish with working automations they can apply in their studies, careers, or businesses.
Through this programme participants will be able to:
  • Understand how AI agents work and where they add value
  • Design and build automated workflows across everyday tools
  • Write effective prompts and instructions for reliable agent behaviour
  • Connect AI agents to apps, data, and APIs
  • Test, monitor, and deploy automations responsibly
